# Baveha — Luxury Fashion eCommerce

Baveha is a modern, high-end fashion eCommerce web application built with **Next.js (App Router)**, **TypeScript**, **React 19**, and a bespoke **Vanilla CSS design system**.

---

## Brand & Aesthetic

- **Visual Tone**: Understated elegance, quiet luxury, generous whitespace, hairline borders (`#e5e0da`), warm off-white tones (`#faf8f5`), rich near-black typography (`#16130f`), and subtle terracotta accents.
- **Typography**: Editorial display serif (*Cormorant Garamond*) paired with clean geometric grotesque (*Inter*).
- **Interactions**: Smooth crossfade hero slideshow, image hover transformations, quick-add drawer, cart persistence with toast notifications, and client-side transitions.

## 🔌 Backend Swap Seam (`lib/api.ts`)

`lib/api.ts` is explicitly engineered as the **single integration seam** between the UI components and the data layer.

All page components and search overlays call the following async functions:
- `getProducts({ category, subcategory, sort, query, limit })`
- `getProductById(id)`
- `getFeatured(limit)`
- `getNewArrivals(limit)`
- `getTrending(limit)`
- `getRelated(id, limit)`
- `searchProducts(query, limit)`

### How to Connect a Real Backend
To switch from mock data to a live backend (Shopify Storefront API, MedusaJS, Supabase, or REST endpoints):
1. Open `lib/api.ts`.
2. Replace the in-memory array filtering with `fetch()` calls to your API endpoints.
3. **No page-level, component-level, or routing changes are required.**

## 📦 Listings Pipeline (`import-listings`)

Easily import new products from CSV and process photos into the active catalogue:

1. Copy `incoming/listings-template.csv` to `incoming/listings.csv`.
2. Add your products row-by-row.
3. Drop corresponding photos into `incoming/images/`.
4. Run:
   ```bash
   npm run import-listings
   ```
5. The pipeline validates required fields, runs macOS `sips` image optimization into `public/images/products/`, and regenerates `lib/generated-products.ts`.

## 🐳 Running with Docker

This project includes an optimized **multi-stage standalone Docker build** (producing a lightweight `~120MB` container with non-root security) and Docker Compose profiles for both production and development.

### 1. Production Mode (Docker Compose)
Runs the optimized standalone production build on port `3000`:
```bash
# Build and start in background
docker compose up --build -d

# View application logs
docker compose logs -f app

# Stop container
docker compose down
```
Access the application at [http://localhost:3000](http://localhost:3000).

### 2. Development Mode with Hot-Reload (Docker Compose)
Mounts source directories and enables hot-reloading for local development:
```bash
# Start development container
docker compose --profile dev up --build

# Stop development container
docker compose --profile dev down
```

### 3. Standalone Docker CLI Commands
```bash
# Build the production image
docker build -t ecommerce-app:latest .

# Run the container
docker run -d -p 3000:3000 --name ecommerce-store ecommerce-app:latest

# View logs
docker logs -f ecommerce-store

# Stop and remove container
docker stop ecommerce-store && docker rm ecommerce-store
```

## 🔑 Google Identity & Multi-Factor Authentication (MFA) Setup

Following the [Google Identity Services Client ID Guide](https://developers.google.com/identity/gsi/web/guides/get-google-api-clientid):

1. **Create OAuth 2.0 Client ID in Google Cloud Console**:
   - Go to [Google Cloud Console Credentials](https://console.cloud.google.com/apis/credentials).
   - Click **+ CREATE CREDENTIALS** &rarr; **OAuth client ID**.
   - Set **Application type**: `Web application`.
   - **Authorized JavaScript origins**:
     - `http://localhost:3000`
     - `http://localhost`
     - `https://your-domain.com`
   - **Authorized redirect URIs**:
     - `http://localhost:3000/login`
   - Copy the generated **Client ID** (e.g. `xxxxxxxx.apps.googleusercontent.com`).

2. **Configure Environment Variable**:
   - Create `.env.local` or set in Docker:
     ```env
     NEXT_PUBLIC_GOOGLE_CLIENT_ID=xxxxxxxx.apps.googleusercontent.com
     ```
   - If no client ID is set during local testing, the application uses zero-config instant development mode with full Google Account Picker & MFA challenge.
